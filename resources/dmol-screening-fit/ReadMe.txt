This folder contains ZblPotential coefficients, based on different datasets from: https://zenodo.org/records/17302337
("Repulsive interatomic potentials calculated at three levels of theory" by K. Nordlund, S. Lehtola and G. Hobler)

Fit was done via the script fit-dmol.py, also found in this folder, if you need specifics on how it was done, then look into it.
Files are written in format
element1 element2 c1 c2 c3 c4 c5 c6 - per line
